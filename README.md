# 🎓 AI Powered Memory Assistant for Students (LearnMate-AI)

An AI-powered educational platform that transforms handwritten notes, PDFs, scanned documents, and images into interactive learning resources such as summaries, flashcards, quizzes, mind maps, and infographics.

---

## 📌 Overview

AI Learning Assistant for Students helps learners reduce manual effort in note preparation and revision by automatically extracting text from uploaded study materials and generating AI-powered learning resources.

The system supports:

- 📄 PDF Documents
- 📝 Handwritten Notes
- ✍️ Manual Text Input

The extracted content is processed using OCR and AI technologies to generate structured learning materials.

---

## ✨ Features

### 📤 Upload Notes

- Upload PDF files
- Upload handwritten notes
- Paste text manually

### 🔍 OCR Text Extraction

Supports:

- Printed text extraction
- Handwritten text recognition
- PDF page rendering
- OCR text cleaning and correction


### 📄 AI Summary Generation

Generate:

- Short Summary
- Detailed Summary
- Key Points

### 📚 Flashcards

Automatically creates:

- Question & Answer pairs
- Interactive flashcard interface
- Click-to-reveal answers

### 🧠 Quiz Generation

Generate AI-powered MCQs:

- Multiple Choice Questions
- Correct Answers
- Explanations
- Score Tracking

### 🗺️ Mind Maps

Visual representation of concepts and topic relationships.

### 🎨 Infographics

Generate visual learning aids from study content.
